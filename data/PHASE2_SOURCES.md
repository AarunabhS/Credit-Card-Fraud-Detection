# Phase-two data and scope

The full 284,807-row Worldline/ULB benchmark replaces the 50,000-row development sample for the new evaluation. Duplicate removal leaves 283,726 records and 473 fraud labels. Time is a split variable, never a predictor. The source remains linked by TensorFlow’s official tutorial; data rights are ODbL/DbCL.

Run `python demo.py`, then open http://127.0.0.1:8765. The demo scores public validation examples and compares frozen validation-derived review policies. Costs are hypothetical relative units; the cost recommendation uses validation outcomes only. The server binds to loopback, restricts routes and payload size, and writes no request data.

Source URLs and immutable hashes are in the accompanying provenance JSON. Original data notices continue to apply.
